# AI 修改图片

先启动本地 ComfyUI，再启动 Mini Manga。打开漫画后，在阅读工具栏点击 **AI修改**，选择模型并输入修改要求，点击 **发送并修改**。双页阅读时处理的是页码框对应的当前页；对话框顶部和原图预览会标明具体页面。

默认使用 **Pony SDXL 动漫局部修改**，使用本机 `http://127.0.0.1:8188`。先在左侧用画笔涂抹目标区域（绿色），再输入目标样式，如 `blue jacket, long sleeves`，点击发送。橡皮可修边，清空选区可重画。Pony 使用英文标签描述目标，质量标签由配置自动补充；它不具备 Flux 那样的自然语言指令理解方式。

这套配置采用 Pony Diffusion V6 XL、Inpaint 遮罩、Xinsir SDXL Canny ControlNet 和 IPAdapter Plus SDXL ViT-H。需要安装 ComfyUI_IPAdapter_plus 及对应四个模型文件；无需另装 Qwen 文本编码器。原来的 **9B质量模式** 和 **4B快速模式** 保留，仍需 ComfyUI-GGUF、对应 FLUX.2 klein 模型、Qwen3 编码器及 FLUX.2 VAE。初次运行或切换模型可能较慢。

展开 **局部修改参数** 可调整：修改强度默认0.95、24步、提示词强度7、结构约束0.4、参考图约束0.1。改动不足时，可将修改强度调至1，或降低结构/参考图约束；小幅修色与人物变化过大时，可把修改强度降至0.55–0.75，并适度提高参考图约束。增大强度不保证质量更好。遮罩覆盖完整目标及少量边缘；未涂抹的地方会从原图保留，局部结果以原图尺寸输出。绿色边缘的半透明像素会混合。大幅改变姿势或遮挡关系通常需要多次分区修改。

Flux 和其他模型也可勾选 **局部修改**：模型仍按自身工作流生成，再由应用按遮罩合成回原图。Pony 则同时在采样阶段使用遮罩。两者区别会影响边缘衔接与目标实现程度。

结果生成后会自动显示预览：

- **保存到当前路径**：另存PNG，文件名包含原页名和唯一ID，不覆盖原图。图片目录和独立图片保存在原图旁；压缩包或PDF保存在原文件同级的 `原文件名_AI` 文件夹，不修改容器。
- **删除**：确认后把本软件的生成结果和已另存的副本移到系统回收站，原图不受影响。历史条目标记为结果已删除。
- **关闭**：保留结果与记录；生成中关闭不会停止任务。可从左侧 **AI修改记录** 返回，按漫画或关键字查找。

任务在本机应用中串行执行，避免争用显存。应用退出或崩溃后，未完成条目标记为失败，不会显示永久生成中。ComfyUI有自己的任务队列和输入/输出目录；本软件不会清理该服务的独立文件。

## 配置其他模型

点击输入窗口中的 **打开模型配置**，会在系统编辑器打开当前用户数据目录内的 `ai/config.json`。修改并保存后，点击 **刷新配置**。0.2.5首次升级会备份旧配置为 `config.json.before-pony`，追加缺少的内置配置和工作流，保留已有模型参数与工作流文件；原默认4B/9B切换到Pony，自定义默认模型保持原值。迁移通过 `presetRevision: 2` 标记，只执行一次。

配置内容包含 `version: 1`、`defaultProfile` 和 `profiles`。每个配置必须有唯一的 `id`、显示名称 `name`、`provider` 和服务 `endpoint`。可选 `apiKeyEnv` 指向API密钥的环境变量名；密钥不需要写到配置或前端。可选 `maxPixels` 控制请求图像面积，默认786432，缩放保留比例并将宽高对齐到16像素，不放大原图。

### ComfyUI

复制一份现有配置，修改 `id`、`name` 和模型加载节点的 `overrides`，即可增加同一工作流的其他模型精度或大小。9B主模型需要配套8B编码器，不能仅替换主模型。

其他工作流使用ComfyUI导出的 **API格式JSON**，放在配置文件旁。设置 `workflow` 为文件名，然后配置 `bindings`：

- `prompt`、`image`、可选 `seed`：包含 `node`（节点ID字符串）和 `input`（输入名称）。
- `width`、`height`：节点绑定数组，同步调整参考图缩放、空白潜空间与调度器尺寸。
- `outputNode`：返回图片的输出节点ID，例如SaveImage节点。
- `overrides`：`{ "node": "1", "input": "unet_name", "value": "模型文件名.gguf" }` 形式的覆盖值数组。
- `mask`：可选的遮罩文件绑定。约定PNG黑色保留、白色修改，工作流使用 `LoadImageMask` 的 red 通道；该工作流同时设置 `requiresMask: true`。
- `promptPrefix`：可选的提示词前缀；`promptHint` 是用户界面的提示说明。
- `parameters`：参数数组，每项为 `{key,label,node,input,min,max,step,default}`，将范围滑块绑定至工作流输入，阅读器无需知道采样或控制节点细节。

模型适配层负责上传图片、填充工作流、提交任务、轮询历史与读取结果。阅读器不依赖ComfyUI节点ID，任务及历史模块也不负责模型推理细节。

### 兼容图片编辑API

可添加：

```json
{
  "id": "other-local-model",
  "name": "其他本地改图模型",
  "provider": "openai-images",
  "endpoint": "http://127.0.0.1:8000/v1",
  "model": "your-edit-model",
  "maxPixels": 786432
}
```

服务需要支持multipart `POST /images/edits`，接收 `image`、`prompt`、`model`、`n`，局部模式额外发送透明区域可编辑的 `mask`，返回 `data[0].b64_json` 或同源图片URL。其他协议可通过新增模型适配器扩展，不需要修改阅读器和记录模块。

配置为远程服务时，当前页图片和输入指令会发送到该服务；默认配置只连接本机。图片输入支持阅读器已有的目录、独立图片、压缩页与PDF页。输出归一化为PNG，最长任务等待20分钟，超时后可查看服务端队列。
